01 / The idea

Build the world.
Not just the tables.

Real data is costly to curate, difficult to share, and often missing the generative truth needed to verify open-ended findings. Exploring files alone can also leave valid insights without matching evaluation criteria.

Data World reverses the process. We specify mechanisms first, construct a coherent canonical state, and project it into realistic, imperfect files. Independent audits check whether selected analytical targets remain recoverable from those observations.

02 / The engine

From mechanisms
to measurable insight.

Independent agent sessions communicate through artifacts. A dependency DAG guides generation; a generative record grounds tasks and rubrics.

01 — SPECIFY

World contract

Define entities, timelines, edge mechanisms, invariants, and observation systems before generating any files.

02 — CONSTRUCT

Canonical state

Build topological layers in order, using committed upstream state as read-only input.

03 — OBSERVE

Realistic imperfections

Project truth through explicit missingness, delays, identifier mismatches, duplicates, and drift.

04 — VERIFY

Audit & supervision

Audit relationships and target recoverability, then generate tasks with atomic positive and negative rubric items.

03 / Evaluation

Beyond getting
the numbers right.

DataWorld-Bench separates data computation from insight discovery. Strong processing does not automatically yield grounded analytical conclusions.

DataWorld-Bench

World-disjoint evaluation

Human preference-based curation selects realistic questions from audited, held-out worlds. Each world contributes a cause and a consequence task.

Two complementary capabilities

Data computation

Recover analyzable data from heterogeneous files: parsing, cleaning, joins, granularity, and metric definitions.

Insight discovery

Answer the question with supported comparisons, relationships, magnitudes, heterogeneity, and limitations.

Rubrics ground selected targets, not every valid insight. Unlisted findings are not penalized merely for being unlisted.

Task-solving evaluation uses mini-swe-agent v2.4.6. Generation and task synthesis use Claude Code. Test worlds are excluded from training.
